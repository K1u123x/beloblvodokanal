Белблводоканал - веб-сервис диспетчерской службы

Система для приема заявок на сантехнические услуги, назначения
работников с рекомендательной системой SVD++ и отслеживания
выполнения работ.

Возможности
1. Регистрация клиентов и создание заявок на услуги
2. Панель диспетчера с распределением заявок между работниками
3. Рекомендательная система (SVD++) для подбора подходящего работника
4. Личный кабинет работника со списком задач и чатом
5. Админ-панель с управлением пользователями, услугами, новостями
6. Отчеты с экспортом в Excel и PDF
7. Адаптивная верстка, темная тема, версия для слабовидящих
8. Чат внутри каждой заявки с автообновлением

В процессе выполнения:
1. Чат через WebSocket
2. Наладить кэширование Redis
И др.

Стек
Python 3.12, Flask 3.0, PostgreSQL 18, SQLAlchemy 2.0,
Bootstrap 5, jQuery, Chart.js, Surprise (SVD++)

Установка
1. Установите PostgreSQL 18 и создайте базу данных vodokanal
2. Склонируйте репозиторий
3. Создайте виртуальное окружение:
   python -m venv venv
   source venv/bin/activate  (Windows: venv\Scripts\activate)
4. Установите зависимости:
   pip install -r requirements.txt
5. Настройте config.py - укажите данные для подключения к БД
6. Заполните базу тестовыми данными:
   python populate_test_data.py
7. Запустите приложение:
   python app.py
8. Откройте http://127.0.0.1:5000

Данные для входа (тестовые)
- Администратор: admin@example.com / admin123
- Диспетчер: dispatcher1@example.com / disp123
- Работник: worker1@example.com / worker123
- Клиент: client1@example.com / client123

Структура проекта
app/
  routes/       - маршруты по ролям
  models.py     - модели базы данных
  forms.py      - формы и валидация
  utils.py      - SVD++, слоты, загрузка фото
  static/       - CSS, JS, изображения
  templates/    - HTML шаблоны
config.py       - конфигурация
populate_test_data.py - наполнение базы тестовыми данными
